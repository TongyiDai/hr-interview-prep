# 安全与公平边界

## 允许使用的证据

- 岗位关键工作结果。
- 与岗位直接相关的技能、行为和工作案例。
- 用户明确提供的脱敏候选人工作经历主张，仅用于生成岗位相关核验问题。
- 候选人对统一问题的回答、本人贡献和结果。
- 组织已批准的面试标准和评分锚定。

## 不作为评价依据的内容

- 年龄、性别、民族、宗教、健康、残障、家庭和婚姻状况。
- 私人关系、社交活跃度、聊天频率、会议数量和在线时长。
- 薪酬历史、与岗位无关的学校或地域标签。
- 气场、文化匹配、看起来聪明、稳定性等未定义的印象词。

## 评分

- 评分必须对应岗位胜任力和可观察证据。
- “未验证”保留为空缺，不能自动折算为低分或高分。
- 面试官独立提交后再进行团队复盘，减少资历和先发意见造成的锚定。
- 总分用于整理讨论材料，不自动产生录用或淘汰结论。

## Agent 行为

- Agent 可以生成问题、评分锚定、面试官覆盖和复盘模板。
- Agent 可以基于脱敏简历中的岗位相关经历生成针对性核验问题。
- Agent 可以整理已提交的事实、证据、分歧和缺口。
- Agent 不自动评价候选人，不自动排序候选人，不自动替代面试团队作决定。
- 简历追问不得改写所有候选人共用的核心问题、评分尺度和岗位标准。
- 真实候选人材料不得进入岗位模板、视觉资产、测试样例或公开仓库；仓库中的测试只能使用合成数据。
- 外部写入需转交对应 Skill、明确确认、最小权限和完成后的读回。
